# Termo de Uso Ético

O Bennu OS é uma ferramenta desenvolvida estritamente para fins educacionais, testes de intrusão autorizados, auditorias de segurança defensiva e competições de CTF (Capture The Flag). 

O usuário concorda em utilizar este software apenas em alvos nos quais possua permissão explícita e por escrito. Os desenvolvedores não se responsabilizam por qualquer uso indevido ou danos causados pelo uso destas ferramentas.
