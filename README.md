# Bennu OS

Distribuição de segurança ofensiva e OSINT, mobile-first, com foco em auditorias autorizadas, labs e CTFs.

## Estrutura de Comandos (CLI)

* `bennu-recon --target <ip>`: Varredura de portas TCP e banner grabbing.
* `bennu-fuzz --target <ip>`: Fuzzing web para descoberta de rotas e diretórios.
* `bennu-ssl --target <ip>`: Verificação de certificados e análise de portas TLS/SSL.
* `bennu-dns --target <dominio>`: Resolução de subdomínios e consultas DNS.
* `bennu-report`: Gerenciador e leitor consolidado do último relatório JSON gerado.

## Escopo Ético
Uso exclusivo para pentest autorizado, ambientes controlados e CTFs. Nenhuma ferramenta possui propósito de acesso não autorizado a sistemas de terceiros.
